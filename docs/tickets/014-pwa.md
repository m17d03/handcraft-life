## Ziel
Das Spiel lässt sich auf dem iPhone zum Home-Bildschirm hinzufügen, startet dort im Vollbild quer und der
Spieler wird einmal freundlich darauf hingewiesen (wegen Safaris 7-Tage-Löschung).

## Kontext
`.claude/skills/touch-steuerung/SKILL.md` (PWA), ADR 0003 (iOS-Eigenheiten), QS U4/S4.

## Scope
- Darf ändern: `public/manifest.webmanifest`, `public/icons/**`, `spiel/index.html` (nur `<head>`), `index.html`
  (nur `<head>`), `src/ui/installhinweis.ts`, `tests/e2e/pwa.spec.ts`
- Darf nicht ändern: übriges `src/`, Projektdokumente

## Abnahmekriterien
- [ ] Manifest mit `display: fullscreen` (Fallback standalone), `orientation: landscape`, `start_url` und `scope`
      unter `/handcraft-life/spiel/`, Theme-Farben Stil A; Icons 180/192/512 (selbst erzeugt, Lizenz in LICENSES.md)
- [ ] `apple-touch-icon`, `apple-mobile-web-app-capable`, Statusleiste
- [ ] Installationshinweis: nur in Safari ohne Standalone, nach dem ersten abgelieferten Auftrag, schliessbar,
      merkt sich das Schliessen
- [ ] E2E: Manifest erreichbar und gültig, Icons laden, Hinweis-Logik (Unit- oder E2E-Test)
- [ ] (Gerät) Zum Home-Bildschirm hinzufügen → Start im Vollbild quer
- [ ] `npm run check` grün
